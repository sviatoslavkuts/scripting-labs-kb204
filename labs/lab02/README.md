## Короткий огляд
Ця лабораторна робота складається з двох практичних завдань:
1. **Модуль безпеки (Task 1):** Об'єктно-орієнтована структура для роботи з користувачами (`User`, `Admin`), управління сесіями (`UserAccount`) та ведення системного журналу (`AuditLog`). Реалізовано безпечне хешування паролів та валідацію пошти.
2. **Агрегатор логів (Task 2):** Клас `EDRLogAggregator`, який парсить файл `edr_alerts.json`, аналізує рівні загроз (`Severity`), типи атак (`ThreatName`) та виявляє неліквідовані події за статусом `ActionTaken`.
